# 叫びブレード

2秒叫ぶと、その声の形が剣になり、声のリズムが剣の斬り方になるブラウザゲーム。剣同士は自動で戦います。

- 声の長さ → リーチ、大きさ → 重さ、高さ → 鋭さと速さ
- 語尾の上げ下げ → 反り、3回以上区切る → 枝刃、声を震わせる → 波刃、澄んだ声 → 片刃
- どれかの能力が80を超えると「異能」（剛剣・長刀・疾風・不動）に目覚める
- 道場の十人を順に倒す「道場破り」。負けたら叫び直して同じ相手に何度でも挑める
- 鍛えた剣は保管庫に残り、自分の剣同士や、制覇後は道場の剣士を選んで「自由対戦」できる
- 「果たし状」で剣をURLにして送れる（声は含まない）

## 遊ぶ
GitHub Pages で公開しています。マイクを使うので https で開いてください。

## 技術
- 1ファイルのHTML（three.js r128 + 後処理を内蔵）
- 声の解析（音量の推移・自己相関による音程・周期性）はすべてブラウザ内で処理し、録音はどこにも送信しません（保管庫の声は端末のIndexedDBに保存）
- 録音のない剣は、仮名を音節に分けて母音の響きと子音を合成した声で叫ぶ
